## 1. 自定义概览

这套配置随包关闭 mpv 内置 OSC，使用 ModernZ，把常用播放操作放在 ModernZ 控制栏，并用脚本统一字幕、播放反馈、截图和队列操作。它继续使用 mpv.net 的播放器、原生窗口和右键菜单，不取代整个宿主界面。

| 模块 | 本包提供的调整 | 使用入口 |
| --- | --- | --- |
| 控制栏 | 基础布局、强调色、速度/音量/增强/截图 四个浮层 | 鼠标操作 |
| 播放 | 精确跳转、长按空格加速、速度循环、Mark、循环及短文字反馈 | 对应热键、鼠标操作 |
| 字幕 | 弹幕接入与控制、字幕延迟、位置/字号调整 | 对应热键、鼠标操作 |
| 播放列表 | 独立侧窗、搜索、拖动排序、移除和同类追加 | Playlist 窗口 |
| 截图/片段 | 源 PNG、三种动态格式导出、自动进入剪贴板 | Screenshot 按钮 |
| 画面增强 | Original、Scaling、Deband、Anime4K-L/S 多种预设方案 | 四角星按钮 |
| 窗口/信息 | 全屏、置顶、100% 请求、媒体信息、统计、控制台 | 对应热键、鼠标操作 |

未设计的播放器默认键有明确屏蔽规则。按钮和快捷动作由本包组合，不能把上游组件全部能力当成本包已接入的入口。

公开配置采用自动显示目标 `target-trc=auto`。Capture 默认是当前 Windows 用户的 Pictures 下 `Capture`，本机路径可以独立覆盖；没有绑定作者机器的输出目录。

这些操作主要改变当前播放实例。Mark、临时字幕调整、增强选择和下次片段复制格式的保存周期各不相同，下面分别说明；没有统一的跨重启会话保存功能。

配置入口：[文件目录与生效规则](configuration.md#1-配置文件与目录速查)、[本机路径](configuration.md#3-本机路径与外部组件)。

## 2. 界面与控制栏

默认控制栏显示在视频上，不预留独立的下方空间。窗口和全屏模式都可自动隐藏；默认底栏从窗口下半区域唤出，顶部窗口按钮使用各自的鼠标触发区域。

| 区域 | 从左到右的主要内容 |
| --- | --- |
| 顶部 | 窗口控制区：最小化、最大化、关闭 |
| 进度条上方 | 媒体标题；hover 预览时换成缩略图、章节和时间信息 |
| 底栏左组 | Info、字幕、音量、时间 |
| 底栏中组 | Previous、−10s、Play/Pause、＋10s、Next |
| 底栏右组 | 画面增强、Speed、Screenshot、Pin、Playlist |

普通文字和图标使用白色，进度轨道为灰色，交互强调色为蓝色。鼠标 hover 的提示、按下反馈和当前浮层选择帮助区分控件状态；不会为每项属性变化持续显示提示。

### 浮层与进度预览

- hover 增强按钮，选择五个增强档之一。
- hover Speed，选择 ×2.0、×1.5、×1.25、×1.0、×0.75、×0.5。
- hover Screenshot，选择 WebP、GIF、MP4 作为下一次片段导出后复制的文件格式。
- hover 音量按钮，用浮层轨道调音量。

四个浮层互斥，移开鼠标后关闭；Speed/增强也保留组件的点击打开行为。选中项为蓝色。速度处在非预设值时，不会把最接近的一项假装选中。

进度条支持左键定位和连续拖动。拖动期间暂时暂停，结束时按开始拖动前的播放/暂停状态恢复；最终定位使用精确 seek。拖出窗口会以最后有效位置结束，切换媒体会清理旧拖动状态。

进度条滚轮向上后退10秒，向下前进10秒。本地视频由 thumbfast 提供缩略图；默认关闭网络缩略图，网络媒体仍保留可取得的时间与章节预览。

预览按“缩略图 → 可用章节名 → 时间 → 进度条”排列。没有章节时不留空行；时间不足一小时为 `mm:ss`，达到一小时为 `hh:mm:ss`。

### 标题与状态反馈

标题默认显示本地文件名；网络媒体使用已有的媒体标题。左键复制本地路径或可用 URL；右键对本地文件在 Explorer 定位，对 URL 用默认浏览器打开。Bilibili CDN 输入优先使用组件传入并校验过的来源 BV/ep/ss 页面。

来源信息不可靠时会提示失败，不会把未知 CDN 地址或前一个文件的来源当作当前网页。缺失分 P 信息时不猜分 P；这项操作不读取浏览器凭据。

播放、seek、速度、字幕等明确动作通常在左上角显示约一秒纯文字反馈，连续操作更新同一条。重新加载和文件切换没有额外的开场提示；大幅原生 seek/音量 OSD 条默认关闭。

视频空白区左键双击切换全屏，右键打开原有菜单。普通左键、中键、滚轮和侧键没有本包新增的空白区操作；拖动窗口仍由宿主处理。控件和局部模式有各自输入区域，鼠标在控件上不应按视频空白区逻辑理解。

调整布局、字号、隐藏规则、颜色、缩略图及鼠标命令，见[界面与缩略图配置](configuration.md#5-界面外观与缩略图)、[快捷键与鼠标配置](configuration.md#6-快捷键与鼠标动作)。

## 3. 播放与音频

### 播放、速度与定位

Space 短按切换播放/暂停。按住达到250ms时临时切到2×并播放，释放后恢复原速度和原暂停状态。失焦、切换媒体或退出会清理临时加速；长按不会在释放时再额外执行一次短按暂停。

Play/Pause 按钮左键只执行播放/暂停，不承担 Space 的长按操作；按钮其他鼠标键默认没有隐藏循环动作。

| 入口 | 当前操作 |
| --- | --- |
| Speed 浮层 | 直接选六档预设速度 |
| Speed 右键 | 恢复1× |
| Speed 滚轮 | 向上加0.25×，向下减0.25× |
| Ctrl+[ | 1 → 0.75 → 0.5 → 1 的较慢循环 |
| Ctrl+] | 1 → 1.25 → 1.5 → 2 → 1 的较快循环 |
| Ctrl+Backspace | 恢复1× |

键盘循环遇到不属于当前循环的速度时先回到1×，例如从0.5×按 Ctrl+] 会回到1×。浮层与滚轮可用来直接选择其他速度；速度反馈显示实际值。

方向键后退/前进3秒，Shift+方向键为1秒，Ctrl+方向键为10秒。底栏中间 seek 按钮左键分别精确后退/前进10秒。媒体可定位范围、解码速度和在线源行为仍影响定位结果。

逗号 `,` 反向逐帧，句号 `.` 正向逐帧；按住句号连续向前逐帧，保持逐帧暂停行为。它们依赖视频轨和播放器逐帧能力，不是对任意网络源的无条件帧精确保证。

Ctrl+R 重新加载当前媒体并继续播放。同输入的显式重载保留本包 Mark 和 A/B 状态；这不是重启播放器，也不会重新读取全部脚本配置。

### Mark 与循环

M 保存当前播放位置，Shift+M 精确跳回。只有一个当前媒体的 Mark；再次保存会替换它。没有 Mark 时提示 `NO MARK`，切换媒体会清除它，不写入跨文件历史。

L 按三步操作：第一次设置 A，第二次设置 B 并循环，第三次清除 A/B。B 必须晚于 A，否则保留 A 并提示。该播放循环与 Screenshot 按钮的导出 A/B 是独立操作。

Ctrl+Shift+L 开关单文件循环。默认不启用整个列表循环或随机播放；自然结束会进入下一项，末项停留。Home/End 和 Previous/Next 的手动队列操作见第5节。

### 音量、音轨与音频输出

| 音量按钮操作 | 行为 |
| --- | --- |
| 左键 | 静音开关 |
| 右键 | 设置100%音量，保留当前静音状态 |
| 中键 | 打开音轨选择器 |
| 滚轮 | 每次加/减5音量单位 |
| hover 浮层轨道 | 点击或拖动调音量 |

默认布局没有独立音轨按钮，音轨选择从音量按钮中键进入。音频设备仍使用播放器原生菜单/选择功能；本包没有给设备选择新增全局快捷键，音量右键也不是设备选择入口。

右键菜单中的 `Custom > Audio > Audio Only / Restore Video` 可以在同文件内隐藏/恢复视频，保留音频播放。同文件恢复之前保存的视频轨；切换媒体会清除上一媒体的恢复记录，视频轨选择由播放器处理。若新媒体的视频轨仍处于关闭状态且媒体含视频轨，可以再次从该菜单执行 Restore Video，交回自动视频选择。纯音频媒体不执行这个视频切换。它是菜单入口，没有 `_` 快捷键。

初始音量、语言偏好、音频延迟和播放参数的个人配置见[播放、音频与字幕配置](configuration.md#4-播放音频字幕与弹幕)。

## 4. 字幕与弹幕

普通字幕操作针对主字幕。弹幕插件管理自己的次字幕轨，二者分开选择和显隐，普通字幕选择器会排除插件生成的弹幕轨。

字幕按钮左键或 S 切换主字幕显隐；右键打开普通字幕轨选择器。按钮提示区分有字幕、字幕关闭和没有字幕；没有普通轨时为禁用状态。Alt+S 打开字幕行选择，PageUp/PageDown 跳到上一/下一字幕时间。

| 调整入口 | 行为 |
| --- | --- |
| Alt+Left / Alt+Right | 字幕延迟减/加0.1秒 |
| Alt+Backspace | 字幕延迟归零 |
| Ctrl+C | 复制当前普通主字幕文本 |
| Ctrl+Shift+S | 进入/退出字幕位置与字号调整模式 |

复制时只使用非空的普通主字幕文本，没有字幕时提示并保留剪贴板现有内容，不改为复制弹幕。

### 位置与字号调整模式

进入模式后，Up/Down 每次改变位置1个百分点，鼠标滚轮每次改变缩放0.05×。这是局部模式：平时 Up/Down 没有这项字幕调整动作。

首次进入保存当前媒体的字幕基准；退出模式保留该媒体临时调整，再次进入继续当前值。切换或结束媒体会退出模式并恢复基准，不把调整写入配置文件。调整期间暂停控制栏自动抬升字幕，避免两套位置规则同时干预。

ASS 内置定位、样式及位图字幕仍有各自的限制；位置/字号操作不保证所有字幕格式都能以相同方式移动或缩放。字幕延迟和轨选择也继续受播放器、媒体轨信息影响。

### Bilibili 弹幕

D 开关组件自己的弹幕轨。组件识别到可用弹幕数据且满足自动显示条件时可自动加载；没有可用弹幕时会提示，不能仅凭一个普通视频文件就生成弹幕。

弹幕占用次字幕槽，保留主字幕选择；次字幕已被其他字幕占用时会提示并跳过，不强行抢占。普通字幕按钮和 S 不代替 D 的弹幕开关。

弹幕转换需要 Python 能运行随包转换脚本，并能访问对应弹幕数据；网页调用还需要已有浏览器与外部入口。缺少这些条件不影响基本播放。默认不为低帧率视频自动添加 fps 滤镜。

弹幕字号、不透明度、滚动时长、底部留白和过滤文件可独立配置；修改后重启并重新生成/加载弹幕。入口见[字幕与弹幕参数](configuration.md#4-播放音频字幕与弹幕)、[本机 Python 路径](configuration.md#3-本机路径与外部组件)。

## 5. 播放列表侧窗

P 或底栏 Playlist 按钮显示/隐藏独立侧窗。侧窗通常贴在主窗右侧，与主窗同顶、同高并跟随位置变化，不预留主视频空间；主窗最大化、全屏或右侧空间不足时改为屏幕右侧覆盖显示。

侧窗自身关闭按钮隐藏侧窗，可再次用 P 打开。可拖动侧窗边缘调整宽度，本实例记住宽度；主播放器退出时侧窗关闭。首次显示尽量保留主窗焦点，之后点击侧窗可以操作列表。窗口跟随受桌面、工作区和宿主窗口状态影响，不是新的系统级窗口管理器。

默认自动队列只补充同目录、同类别的音视频：视频补视频，音频补音频，不自动混入图片、其他文件或子目录。已有队列不会因这条规则自动清理。

| 在侧窗中操作 | 行为 |
| --- | --- |
| 双击条目 | 跳到该条目 |
| 普通 Delete | 仅从队列移除，不删除磁盘文件 |
| 拖动条目 | 重排真实队列，保持当前媒体身份 |
| 从 Explorer 拖入文件 | 手动追加符合当前音频/视频类别的文件 |
| Ctrl+F | 在底部打开搜索并选中文本 |
| 搜索中的普通 Escape | 关闭搜索 |

Ctrl+F、Delete、Escape 是侧窗局部操作，不是全局播放器快捷键；额外修饰键不应假定触发相同动作。搜索文本框编辑期间不把文字输入转发为播放器动作。

搜索只过滤视图，不修改真实队列。过滤后的跳转、移除与排序仍按原条目身份处理，不会把显示行号当真实队列索引。普通底部显示当前项/总数，搜索时显示匹配数量。

本地条目 hover 提示完整路径，网络条目提示标题与 URL。长文本按窗口宽度显示，不把它们当新的日志导出或网络历史管理功能。

Home/End 或 Previous/Next 左键切换上一/下一媒体。手动操作到边界时重播当前项，这不是 Ctrl+R 的保留标记重载入口；自然播放结束则进入下一项，最后一项停留。Previous/Next 其他鼠标键默认解绑，不含隐藏随机或菜单动作。

侧窗会转发一组现有播放器键，但搜索、选择器、控制台和字幕调整有各自焦点边界。修改 input.conf 不保证侧窗任意键位都同步改变；具体配置边界见[快捷键说明](configuration.md#6-快捷键与鼠标动作)及[队列配置边界](configuration.md#7-截图片段与播放列表)。

## 6. 截图与动态片段

Screenshot 按钮集中了源截图、片段标记、输出目录和默认复制格式。默认根目录为 Windows 当前用户的 Pictures 下 `Capture`，可用本机 `capture_root` 指定其他目录。

| 操作 | 行为 |
| --- | --- |
| 左键 | 保存源 PNG，并把图像复制到剪贴板 |
| 右键第一次 | 记录导出起点 A |
| 右键第二次 | 记录晚于 A 的 B，异步导出 MP4、WebP、GIF |
| hover 选择 WebP/GIF/MP4 | 指定下一次导出后复制哪个文件 |
| 中键 | 打开 Capture 根目录；必要时创建该根目录 |

PNG 使用源视频帧，排除软字幕、OSD、控制栏和窗口；源内已经烧录的文字仍在。它不是播放器窗口截图。具体截图处理仍受输出驱动影响，不把 PNG 解释为所有渲染和色彩链路的无损复刻；播放器截图语义可参看[mpv 官方说明](https://mpv.io/manual/stable/#screenshot-commands)。

### A/B 导出与复制格式

先在起点右键，再播放或 seek 到终点右键。B 必须大于 A，错误终点会保留 A 并提示；切换媒体清除待导出的 A。忙时拒绝新截图与片段导出，中键打开目录仍是独立操作。确认有效音视频源并开始导出后会清除 A；异步导出失败也不会把 A 自动恢复。

每次有效导出生成三种文件。hover 选项只决定成功后向剪贴板复制哪个文件，不改变“生成三种格式”的规则，也不会立即复制过去的文件。

新实例默认复制 WebP。选择在当前实例跨媒体保留，重新打开恢复 WebP；B 点冻结当前任务的复制格式。导出期间改变选项只影响以后任务，不改变已开始的任务。

| 输出 | 当前默认处理 |
| --- | --- |
| PNG | 源图像，实际保存为 PNG |
| MP4 | 源分辨率/帧率，H.264 CRF18、fast、8-bit yuv420p；奇数尺寸补齐偶数 |
| MP4 音频 | 已选内置/外部音轨，AAC192k，并考虑 audio-delay；未选择音轨时无音频 |
| WebP | 从 MP4 派生，最大边界框960×960、最高20fps、quality75，循环 |
| GIF | 从 MP4 派生，最大边界框640×640、最高12fps、128色 Bayer 抖动，循环 |

选中的音视频轨若缺少导出所需的源文件或流索引信息，会提示失败；不会猜测另一个音轨替代。

WebP/GIF 保持比例，不放大源图像、不抬高低帧率素材的帧率。GIF 的时间量化可能使实际帧间隔与标称帧率有差异。

导出按源时间线处理，不应用播放倍速，也不烧入软字幕、弹幕或控制栏。MP4 的8-bit编码是兼容取舍；不能据此认为 HDR 或原色彩链路被无损保留。在线源的读取权限、可定位性和请求条件也会影响导出。

### 输出组织与依赖

输出按媒体标题创建安全子目录：去掉一个已识别媒体后缀，例如 `Show.mkv` → `Show`；`Episode.01` 这样的普通标题不去掉 `.01`。非法字符和保留设备名会安全化。

文件名包含安全标题、保存日期时间和实际扩展名。已有文件不覆盖，旧目录不迁移；打开目录使用根目录，而不是推断上一份媒体的输出位置。

源 PNG 与目录入口不依赖 FFmpeg，片段导出需要可用 FFmpeg。缺少依赖或处理失败时会提示，失败只清理本任务产生的文件，不清空剪贴板；播放器正常关闭会取消自己的导出任务。

路径和功能边界见[本机路径配置](configuration.md#3-本机路径与外部组件)、[截图与片段配置](configuration.md#7-截图片段与播放列表)。当前没有可通过新增 conf 字段改 CRF、尺寸、帧率或默认持久格式的接口。

## 7. 增强与显示

增强按钮是空心四角星；hover 或现有点击入口打开五档选择。新实例默认 Original，选中项在本实例跨媒体保留。每个媒体加载时重新捕获它的原始渲染基准，回到 Original 会恢复该媒体基准。

| 档位 | 主要效果 | 条件与边界 |
| --- | --- | --- |
| Original | 保留/恢复当前媒体基础渲染设置 | 初始默认；不等于清空用户所有播放器配置 |
| Scaling | 使用预设缩放器和抗振铃设置 | 需要 gpu/gpu-next 渲染输出 |
| Deband | Scaling 基础上启用预设去色带 | 具体画质取决于素材，可能影响细节 |
| Anime4K-L | 固定较轻 CNN shader 链 | 可识别 SDR、允许开关和 shader 文件齐备 |
| Anime4K-S | 固定较强 CNN shader 链 | 相同 SDR 门槛，资源需求取决于 GPU/素材 |

PQ、HLG、未知传递曲线或不满足 SDR 峰值条件的素材不启用 Anime4K。配置中的允许开关只是放行条件之一，不是确认用户 GPU 已完成验证。

档位控制缩放、去色带和 shader 组，不改变色彩目标、主输出驱动、硬解或播放帧率。默认自动显示目标不是 ICC 校准，也没有把所有显示器强制当作 sRGB。

选择失败时实现尝试回滚受控组并取消成功高亮；可用性和报错应按当前素材/渲染器观察。档名不承诺所有画面都更好或所有 GPU 都实时播放。

没有补帧、RIFE 或自定义组合档。本包也不持久保存上次档位。参数与覆盖关系见[增强与显示配置](configuration.md#8-增强与显示目标)。

## 8. 窗口、信息与快捷操作

Enter 或视频空白区左键双击切换全屏。Ctrl+T 或 Pin 切换置顶，并显示置顶状态反馈。顶部最小化、最大化、关闭继续使用宿主窗口操作。

Ctrl+0 先离开全屏/最大化，再请求100%窗口比例；窗口仍可能按工作区大小约束，因此不是保证超大视频在屏幕上实现完整像素1:1显示。

Info 按钮、Ctrl+I 或 Ctrl+M 打开媒体信息。真实本地文件使用原生 MediaInfo 对话框；网络或其他非真实本地输入使用独立只读辅助窗口，展示当前媒体可取得的信息。

Tab 开关播放器统计，反引号打开控制台。Alt+O 切换 ModernZ 的显示状态；这不重读配置文件，也不切换回原生 OSC。

时间显示右键或 Ctrl+Shift+C 复制当前 `HH:mm:ss.SSS` 时间。没有可读时间时不进行复制。

Ctrl+Shift+V 仅在明确操作时读取剪贴板，加载一条 HTTP(S) URL 并替换当前输入。先去掉首尾空白，余下的内容若仍包含空白、多条地址或本地路径，则不作为此入口接受的 URL；没有浏览器 Cookie 同步或网页嗅探功能。
