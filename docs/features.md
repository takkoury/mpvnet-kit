## 1. 自定义概览

这套配置随包关闭 mpv 内置 OSC，使用 ModernZ，把常用播放操作放在 ModernZ 控制栏，并用脚本统一字幕、播放反馈、截图和队列操作。它继续使用 mpv.net 承载播放与菜单命令，由套件统一常用窗口和右键菜单的外观。

| 模块 | 本包提供的调整 | 使用入口 |
| --- | --- | --- |
| 控制栏 | 基础布局、强调色、速度/音量/增强/截图 四个浮层 | 鼠标操作 |
| 播放 | 精确跳转、长按空格加速、速度循环、Mark、循环及短文字反馈 | 对应热键、鼠标操作 |
| 字幕 | 弹幕接入与控制、字幕延迟、位置/字号调整 | 对应热键、鼠标操作 |
| 播放列表 | 独立侧窗、搜索、拖动排序、移除及文件／单层文件夹追加 | Playlist 窗口 |
| 截图/片段 | 源 PNG、MP4/WebP/GIF任选一种导出、自动进入剪贴板 | Screenshot 按钮 |
| 画面增强 | Original、Scaling、Deband、Anime4K-L/S 多种预设方案 | 四角星按钮 |
| 窗口/信息 | 全屏、置顶、100% 请求、媒体信息、统计、控制台 | 对应热键、鼠标操作 |
| 常用设置 | 字幕、声音、窗口、控制栏、解码、输出路径与快捷键 | 右键“工具与设置 > 常用设置…” |

未设计的播放器默认键有明确屏蔽规则。按钮和快捷动作由本包组合，不能把上游组件全部能力当成本包已接入的入口。

公开配置采用自动显示目标 `target-trc=auto`。Capture 默认是当前 Windows 用户的 Pictures 下 `Capture`，本机路径可以独立覆盖；没有绑定作者机器的输出目录。

这些操作主要改变当前播放实例。Mark、临时字幕调整、增强选择和下次片段导出格式的保存周期各不相同，下面分别说明；没有统一的跨重启会话保存功能。

配置入口：[文件目录与生效规则](configuration.md#1-配置文件与目录速查)、[本机路径](configuration.md#3-本机路径与外部组件)。

### 常用设置

右键选择“工具与设置 > 常用设置…”可调整八类设置。左侧搜索覆盖各分类和具体快捷键，点击结果即可定位；快捷键页另有动作和按键搜索。常用设置中心提供 195 项快捷键动作，默认仍为 40 个全局键盘映射，无需为每项动作绑定按键。

字幕页可排序优先语言、选择本机字体、调整位置和缩放。固定字幕示例不依赖视频是否有字幕；控制栏页显示所属播放器底部的实时画面，并临时显示控制栏，离页或关闭后恢复正常显隐。输出目录和外部程序可通过“浏览…”选择，也可粘贴路径。

“保存本页”只保存当前分类；切换分类保留草稿。关闭时选择“保存”会依次保存所有未保存分类，全部成功后关闭；中途失败保留已保存部分和其余草稿。“不保存”仅放弃尚未提交的修改，“取消”返回编辑。生效时机、预览及冲突处理见[常用设置说明](configuration.md#常用设置)。

v0.4.0 的字幕语言默认按中文、日语、英语排列，默认显示普通字幕；音轨不指定优先语言，由播放器根据媒体选轨。已有用户覆盖优先应用，没有覆盖的项目沿用实际生效的启动配置；未做自定义时使用新包默认。v0.3.0 未指定这三项默认，升级说明见[安装指南](installation.md#6-重新安装与个人配置维护)。

快捷键统一在常用设置中编辑。高级配置编辑器、媒体信息、选择器及播放统计等入口各自按下文说明工作。

“工具与设置 > 帮助 > 关于 mpv.net”显示当前播放器、mpv、FFmpeg 和 MediaInfo 版本。“许可与文件日期”可展开查看版权、许可和文件最后修改日期，文字可选择复制；读取失败的项目显示“未能读取”。重复打开会唤回已有窗口，Esc 可关闭。

## 2. 界面与控制栏

默认控制栏显示在视频上，不预留独立的下方空间。窗口和全屏模式都可自动隐藏；默认底栏从窗口下半区域唤出，顶部窗口按钮使用各自的鼠标触发区域。

宽窗保持单行，竖屏或窄窗将播放控制与工具分成两行；再缩窄时，放不下的功能收入“更多”（竖向三点）。优先保留音量、字幕、截图与片段、播放列表，播放按钮始终可用。极矮窗口优先收纳工具，标题允许省略，时间优先；下表描述完整功能顺序，不表示所有尺寸下都直接显示。

点击“更多”打开收纳项。包含多项操作的功能会在同一面板内打开对应页面，可点击顶部返回。面板太矮时可用滚轮查看其他项。按 Esc、点击面板外部或调整窗口大小都会关闭面板。增强不可用的原因显示在面板底部。在倍速页右键可直接恢复 1×。

| 区域 | 从左到右的主要内容 |
| --- | --- |
| 顶部 | 窗口控制区：最小化、最大化、关闭 |
| 进度条上方 | 媒体标题；悬停预览时换成缩略图、章节和时间信息 |
| 底栏左组 | Info、字幕、音量、时间 |
| 底栏中组 | Previous、−10s、Play/Pause、＋10s、Next |
| 底栏右组 | 画面增强、Speed、Screenshot、Pin、Playlist |

普通文字和图标使用白色，进度轨道为灰色，交互强调色为蓝色。悬停提示、按下反馈和浮层中的选中标识帮助区分控件状态；属性变化不会持续触发提示。

### 浮层与进度预览

- 悬停增强按钮，选择五个增强档之一。
- 悬停 Speed，选择 ×2.0、×1.5、×1.25、×1.0、×0.75、×0.5。
- 悬停 Screenshot，选择 WebP、GIF 或 MP4 作为下一次片段的导出格式。
- 悬停音量按钮，通过浮层中的轨道调整音量。

四个浮层互斥，移开鼠标后关闭；Speed 和增强也可通过原有点击入口打开。选中项为蓝色。速度处在非预设值时，不高亮其他预设项。

控制栏的悬停提示说明可用的中键、右键和滚轮操作；名称、数值、状态及左键用途不在提示中重复。音量、倍速和相机的说明位于功能浮层上方，不抬高控制栏，空间不足时省略。时间提示为“右键复制时间”，倍速不重复提示悬停操作。音量按钮左键静音、中键选音轨、右键恢复 100%，数值显示在功能浮层内。

已知按键名称以鼠标图示呈现：高亮滚轮表示中键，高亮右上按键表示右键，上下箭头表示滚动，旁边只保留动作文字。音量不显示滚轮说明，但滚轮调节仍可用。图示不新增可点击区域。

进度条支持左键定位和连续拖动。拖动期间暂时暂停，结束时按开始拖动前的播放/暂停状态恢复；最终定位使用精确 seek。拖出窗口会以最后有效位置结束，切换媒体会清理旧拖动状态。

进度条滚轮向上后退10秒，向下前进10秒。本地视频由 thumbfast 提供缩略图；默认关闭网络缩略图，网络媒体仍保留可取得的时间与章节预览。

预览按“缩略图 → 可用章节名 → 时间 → 进度条”排列。没有章节时不留空行；时间不足一小时为 `mm:ss`，达到一小时为 `hh:mm:ss`。

章节标题中的花括号、反斜杠等作为普通文字显示；长标题按可用宽度省略。窗口窄到连章节省略提示也放不下时暂不显示章节行，时间与缩略图仍保持原有顺序。

### 标题与状态反馈

标题默认显示本地文件名；网络媒体使用已有的媒体标题。左键复制本地路径或可用 URL；右键对本地文件在 Explorer 定位，对 URL 用默认浏览器打开。Bilibili CDN 输入优先使用组件传入并校验过的来源 BV/ep/ss 页面。

来源信息不可靠时会提示失败，不会把未知 CDN 地址或前一个文件的来源当作当前网页。缺失分 P 信息时不猜分 P；这项操作不读取浏览器凭据。

播放、跳转、倍速、字幕、截图／片段、增强和弹幕等操作在左上角显示中文反馈：即时操作约1.5秒，复制、保存等完成结果约2秒，失败及不可用原因约4秒。连续操作显示最新一条，不逐条排队。

片段导出期间保留“正在导出片段…”，弹幕加载期间保留“正在加载弹幕…”，完成或失败后改为结果提示。换片会结束原弹幕加载，已经开始的片段导出则继续。字幕调整模式保留提醒，调整后显示位置和字号，退出、还原或换片后结束；模式外的单次调整仍只短暂显示。其他操作的短提示结束后，仍在进行的状态会重新显示。打开控制台或选择器时暂时隐藏这些持续提醒；关闭OSD时也不会强制显示。其他原生提示和播放统计保留各自的显示规则。

重新加载和文件切换没有额外的开场提示；大幅原生 seek/音量 OSD 条默认关闭。

播放失败时显示固定提示：不识别的格式建议尝试其他文件，其他错误建议检查文件或URL。不回显后端错误中的私人路径或网址，正常停止、播完和退出不新增提示。

视频空白区左键双击切换全屏，右键打开中文分类菜单。普通左键、中键、滚轮和侧键没有本包新增的空白区操作；拖动窗口仍由宿主处理。控件和局部模式有各自输入区域，鼠标在控件上不应按视频空白区逻辑理解。

### 中文右键菜单

| 分类 | 主要入口 |
| --- | --- |
| 文件 | 打开/追加媒体、光盘、文件位置或来源网页、近期文件、播放历史、稍后继续播放 |

| 字幕与弹幕 | 普通字幕选择/显隐、外挂字幕、位置/字号调整与恢复、延迟、复制、弹幕 |
| 音频 | 音轨、输出设备、外挂音频、音量、延迟、仅音频/恢复视频 |
| 画面 | 五档增强、视频轨、宽高比、旋转、去隔行、缩放/平移、色彩与硬解 |
| 截图与片段 | 源PNG、片段A/B、导出格式、复制最近片段、输出目录、原生截图 |
| 窗口与界面 | 播放列表侧窗、控制栏、全屏、置顶、边框、窗口尺寸与位置 |

没有普通“退出”项；“播放 > 循环与队列 > 保存进度并退出”保留原生保存进度功能。光盘、原生截图、样式覆盖、配置编辑和系统集成等低频入口仍保留。菜单为这些功能提供入口，不自动开启循环、打乱队列或执行系统设置。

“截图与片段 > 原生截图”遵从mpv原生截图选项与输出目录；主入口“保存源画面PNG”使用本包Capture流程，两者明确分开。普通字幕操作排除弹幕轨；高级主／次字幕选择入口保留，手动选择次字幕可能影响占用该槽的弹幕。

菜单采用统一的深色外观，悬停、展开路径与当前状态分别显示。动作旁显示当前生效的套件快捷键，取消绑定后对应提示也会清空；不增加新的全局键。近期文件、轨道、章节、配置方案及音频设备仍由播放器生成和执行。长菜单可滚动，长标题可停留查看。宿主不兼容或样式加载失败时保留原菜单。

查看媒体信息可用“工具与设置 > 媒体信息”。编辑 mpv.conf、input.conf 和 ModernZ 配置，以及打开配置目录，都可在常用设置的“高级”页操作，已有快捷键动作仍可使用。“工具与设置 > 配置”下保留“打开配置编辑器…”和“原生快捷键编辑器（高级）…”。媒体名称、设备名及少量原生动态文字保留原值。

调整布局、字号、隐藏规则、颜色、缩略图及鼠标命令，见[界面与缩略图配置](configuration.md#5-界面外观与缩略图)、[快捷键与鼠标配置](configuration.md#6-快捷键与鼠标动作)。

## 3. 播放与音频

### 播放、速度与定位

Space 短按切换播放/暂停。按住达到250ms时临时切到2×并播放，释放后恢复原速度和原暂停状态。失焦、切换媒体或退出会清理临时加速；长按不会在释放时再额外执行一次短按暂停。

Play/Pause 按钮左键只执行播放/暂停，不承担 Space 的长按操作；按钮其他鼠标键默认没有隐藏循环动作。

| 入口 | 当前操作 |
| --- | --- |
| Speed 浮层 | 直接选六档预设速度 |
| Speed 右键 | 恢复1× |
| Speed 滚轮 | 向上加0.25×，向下减0.25× |
| Ctrl+[ | 1 → 0.75 → 0.5 → 1 的较慢循环 |
| Ctrl+] | 1 → 1.25 → 1.5 → 2 → 1 的较快循环 |
| Ctrl+Backspace | 恢复1× |

键盘循环遇到不属于当前循环的速度时先回到1×，例如从0.5×按 Ctrl+] 会回到1×。浮层与滚轮可用来直接选择其他速度；速度反馈显示实际值。

方向键后退/前进3秒，Shift+方向键为1秒，Ctrl+方向键为10秒。底栏中间 seek 按钮左键分别精确后退/前进10秒。媒体可定位范围、解码速度和在线源行为仍影响定位结果。

逗号 `,` 反向逐帧，句号 `.` 正向逐帧；按住句号连续向前逐帧，保持逐帧暂停行为。它们依赖视频轨和播放器逐帧能力，不是对任意网络源的无条件帧精确保证。

Ctrl+R 重新加载当前媒体并继续播放。同输入的显式重载保留本包 Mark 和 A/B 状态；这不是重启播放器，也不会重新读取全部脚本配置。

“工具与设置 > 屏幕内选择器 > 播放列表…”可在画面内查找并选择播放项，适合全屏时快速选片；P仍打开用于管理队列的侧窗。条目右侧是队列序号，蓝色标记表示正在播放的条目，完整路径可搜索或停留查看。列表重排后仍按原条目选择，条目已移除时会提示重新选择；再次选择当前项沿用播放器的重播行为。此列表不提供删除或排序，Esc取消不改变队列。

“工具与设置 > 屏幕内选择器 > 主菜单…”提供可查找的屏幕内入口，按当前媒体显示可用的轨道、章节、版本等项目。选择后打开对应选择器或工具；内容变化时会更新列表，Esc取消。常用设置统一承接配置和快捷键编辑；“文件信息（统计）”与“快捷键帮助（统计）”仍打开原统计页面。屏幕内播放列表用于选片，侧窗用于队列管理。

“工具与设置 > 屏幕内选择器 > 播放器属性…”显示打开时的属性快照，可按属性名或值查找。列表中的长值会省略；点击或Enter沿原有方式临时显示该项详情，Esc取消。播放位置等值不会在阅读中不断刷新，重新打开可读取最新值。该入口用于查看技术属性，不编辑设置。

“工具与设置 > 屏幕内选择器 > 快捷键…”用于查找并执行当前生效的快捷键动作，不修改绑定。左侧显示动作名称或自定义命令，右侧显示按键；按名称、按键或命令查找，停留或键盘聚焦可查看原命令。点击或按Enter会关闭列表并执行，Esc取消；绑定在选择期间变化时会提示重新打开。需要编辑绑定时，使用常用设置中的“快捷键”页。

Alt+S 或“字幕与弹幕 > 选择字幕行…”可查找当前主字幕的文字，选中后跳到对应时间。列表沿用按秒定位，应用当前字幕延迟；长句停留或键盘聚焦后显示完整内容。蓝色标记表示播放位置附近的参考行，不代表当前一定正在显示该句。Esc、关闭按钮或点击面板外取消，不改变播放位置。

读取字幕行需要FFmpeg；可在常用设置中指定其路径，或使用PATH中的程序。内嵌和外挂文本字幕均可读取，图形字幕不做文字识别。字幕隐藏时仍可查找，但不会自动开启显示；切换主字幕会重新读取，切换媒体或关闭面板会取消本次提取。

“文件 > 稍后继续播放…”列出保存过进度的媒体，按记录更新时间从新到旧排列。可按名称或路径查找，同名文件附目录；停留或键盘聚焦可查看完整路径。选择后由播放器按当前设置恢复进度，关闭恢复时会提示；取消不改变播放或保存记录。列表没有清空功能，正常恢复后记录由播放器按原有规则处理。

该列表需要保存记录包含媒体路径；缺失时会提示启用`write-filename-in-watch-later-config`后重新保存进度。选择器不会替用户启用记录或改变恢复设置。文件读取失败或在选择期间变化时，会提示重试或重新选择。

从“文件 > 播放历史…”或屏幕内主菜单的“播放历史”打开同一列表，可按名称或完整路径查找最近记录。时间显示在名称下方，同名文件附父目录短名。鼠标停留或用方向键聚焦条目可查看完整路径。选择后由播放器打开该媒体，是否恢复进度沿用原有设置。按 Esc、点击关闭按钮或面板外部可取消。记录变化时会要求重新选择。

右下角“清空历史…”经确认后清除全部播放历史，包括搜索时未显示的记录；媒体文件和保存的播放进度不受影响。取消保留记录，文件被占用或已变化时会提示重试。列表不会自动启用历史记录；没有记录、尚未启用和读取失败会分别说明。

“工具与设置 > 屏幕内选择器 > 全部轨道…”按视频、音轨、主字幕分组，可切换分类并搜索。条目较多时只滚动列表，组标题保持可见；各组分别标记当前轨道，再次选择当前项只关闭该类型。主字幕列表包含弹幕轨，已被次字幕使用的轨道不能重复选择。重新打开恢复“全部”并清空查找。Tab可移到分类，左右键切换分类；方向键选轨，Enter确认，Esc取消。

“工具与设置 > 屏幕内选择器 > 章节…”显示可搜索的章节标题和起始时间。点击或用方向键移动后按 Enter 跳到该章开头，再次选择当前章也会回到章首；Esc、关闭按钮或点击画面内面板外区域可取消，不改变播放位置。无标题的章节显示“章节 N”。没有章节时显示空状态；媒体切换会关闭列表，章节列表在选择期间发生变化时会提示重新选择。

“播放 > 选择媒体版本…”用于切换同一文件提供的不同版本（Edition），无标题时显示“版本 N”。不足两个版本时显示说明，不提供切换操作。点击条目或用方向键选中后按 Enter 可切换，再次选择当前版本也不会关闭视频轨。按 Esc、点击关闭按钮或面板外部可取消。切换版本可能重新加载媒体并改变播放位置，章节和轨道也可能随版本变化。

### Mark 与循环

进度条上侧的蓝色三角标记循环 A/B；仅A时显示端点，设置有效B后显示循环区间，清除循环时消失。标记随控制栏隐藏；短标签挤在一起时可悬停查看“循环”或“片段”及端点时间，不改变原有拖动定位。

M 保存当前播放位置，Shift+M 精确跳回。当前媒体只保留一个 Mark，再次保存会替换它。尝试跳回时没有标记会提示“尚无播放标记”。切换媒体会清除标记，不写入跨文件历史。

L 按三步操作：第一次设置 A，第二次设置 B 并循环，第三次清除 A/B。B 必须晚于 A，否则保留 A 并提示。该播放循环与 Screenshot 按钮的导出 A/B 是独立操作。

Ctrl+Shift+L 开关单文件循环。默认不启用整个列表循环或随机播放；自然结束会进入下一项，末项停留。Home/End 和 Previous/Next 的手动队列操作见第5节。

### 音量、音轨与音频输出

音量浮层采用适度放大比例，数值与滑块更明显；轨道两侧也可拖动调节，数值区域不响应调音量。音量范围和下列操作保持。

| 音量按钮操作 | 行为 |
| --- | --- |
| 左键 | 静音开关 |
| 右键 | 设置100%音量，保留当前静音状态 |
| 中键 | 打开音轨选择器 |
| 滚轮 | 每次加/减5音量单位 |
| 悬停后显示的浮层轨道 | 点击或拖动调音量 |

默认布局没有独立音轨按钮，音轨选择从音量按钮中键进入。音频输出设备可从“音频 > 屏幕内设备选择器…”选择；没有为它新增全局快捷键，音量右键也不是设备选择入口。

设备列表显示易读名称，停留或键盘聚焦后可查看完整标识，同名设备会增加标识后缀以便区分。右三角表示已选配置；“自动选择”由播放器决定输出，不代表某个具体扬声器。重复选择当前设备保持选择，Esc、关闭按钮或面板外点击取消；设备已不在列表或提交失败时提示重选。此操作只改变当前播放器的输出选择，不修改系统默认设备、音量、静音或长期配置。

“音频 > 选择音轨…”与音量按钮中键打开同一个可搜索列表。右三角和加粗名称表示当前音轨；点击或用方向键移动后按 Enter 切换，再次选择当前音轨或选择“关闭音轨”会停止该媒体的音轨播放，不改变静音、音量或音频设备设置。Esc、关闭按钮或点击画面内面板外的区域可取消，不改变选择。列表显示语言、格式、声道和来源；停留或用方向键聚焦可查看完整标题、采样率、码率等信息。无音轨时显示空状态，切换媒体会关闭旧列表。

右键菜单中的“音频 > 仅音频／恢复视频”可以在同文件内隐藏/恢复视频，保留音频播放。同文件恢复按钮之前保存的视频轨；切换媒体或在选择器中明确改选会清除旧恢复记录。若当前没有可恢复记录且媒体含视频轨，再次执行该菜单动作会交回自动视频选择。纯音频媒体不执行这个视频切换。它是菜单入口，没有 `_` 快捷键。

“画面 > 选择视频轨…”显示可搜索的视频轨及分辨率、格式、帧率和来源。右三角与加粗名称标记当前轨；再次选择当前轨或选择“关闭视频画面”会关闭画面，音频保持。Esc、关闭按钮或面板外点击可取消；长标题及更多信息可停留查看。缺失字段显示短横，静态图像／封面不显示虚假的帧率。

初始音量、语言偏好、音频延迟和播放参数的个人配置见[播放、音频与字幕配置](configuration.md#4-播放音频字幕与弹幕)。

## 4. 字幕与弹幕

外挂字幕按原生fuzzy规则自动加载：字幕文件名需包含视频文件名，支持附加发布/语言后缀；除当前目录，还搜索`sub`、`subs`、`subtitles`、`字幕`子目录，不递归扫描、不加载所有无关集数。两者命名差别较大时仍需手动加载。加载进轨道列表与默认选中是两回事，语言/内封轨道选择继续使用播放器原有策略。

普通字幕操作针对主字幕。弹幕插件管理自己的次字幕轨，二者分开选择和显隐，普通字幕选择器会排除插件生成的弹幕轨。

“字幕与弹幕 > 高级”中的“主字幕轨选择…”和“次字幕轨选择…”会列出全部字幕轨，包括弹幕轨。每个入口只修改对应字幕槽。同一轨道不能同时占用两个槽，已用于另一槽的轨道会变暗并说明原因。再次选择当前轨，或选择对应的“不使用主字幕”或“不使用次字幕”，可关闭目标槽。取消不改变选择。次字幕槽用于弹幕时会显示提示。选轨不会自动开启已隐藏的字幕，也不会更改弹幕渲染和样式设置。

“选择普通字幕…”在画面内显示可搜索列表，蓝色右三角和加粗名称表示当前轨道。点击条目或用方向键移动后按 Enter 即可选择；再次选择当前轨道，或选择“不显示普通字幕”，会关闭普通字幕。Esc、关闭按钮或点击画面内面板外的区域可取消，不改变原选择。轨道在操作前被移除时会提示重新选择；切换媒体会关闭旧列表。搜索支持中文和粘贴，长标题停留后显示完整内容；没有普通字幕时显示空状态。选择器关闭后恢复播放器原有输入，控制台使用输入时不会同时打开选择器。

字幕按钮左键或 S 切换主字幕显隐。中键打开普通字幕轨选择器，右键进入或退出字幕位置与字号调整模式。没有普通字幕轨时按钮禁用，悬停提示只说明可用的额外操作。Alt+S 打开字幕行选择，PageUp/PageDown 跳到上一或下一字幕时间。v0.2.0 的鼠标映射不同：右键选轨，中键无动作。

| 调整入口 | 行为 |
| --- | --- |
| Alt+Left / Alt+Right | 字幕延迟减/加0.1秒 |
| Alt+Backspace | 字幕延迟归零 |
| Ctrl+C | 复制当前普通主字幕文本 |
| Ctrl+Shift+S | 进入/退出字幕位置与字号调整模式 |

复制时只使用非空的普通主字幕文本，没有字幕时提示并保留剪贴板现有内容，不改为复制弹幕。

### 位置与字号调整模式

进入模式后，Up/Down 每次改变位置1个百分点，鼠标滚轮每次改变缩放0.05×。这是局部模式：平时 Up/Down 没有这项字幕调整动作。

首次进入模式或使用菜单单次调整时保存当前媒体的字幕基准；退出模式保留该媒体临时调整，再次进入继续当前值。菜单“字幕与弹幕 > 位置与字号”可单次移动或改变字号，步长与模式内相同，模式外使用不会接管方向键或滚轮。

“字幕与弹幕 > 恢复字幕位置与字号”恢复首次保存的基准，并退出调整模式、恢复控制栏自动避让；不影响字幕延迟、轨道或弹幕，没有调整记录时保持原值。切换或结束媒体仍会自动恢复基准，不把调整写入配置文件。临时调整期间暂停控制栏自动抬升字幕，避免两套位置规则同时干预。

ASS 内置定位、样式及位图字幕仍有各自的限制；位置/字号操作不保证所有字幕格式都能以相同方式移动或缩放。字幕延迟和轨选择也继续受播放器、媒体轨信息影响。

### Bilibili 弹幕

D 开关组件自己的弹幕轨。组件识别到可用弹幕数据且满足自动显示条件时可自动加载；没有可用弹幕时会提示，不能仅凭一个普通视频文件就生成弹幕。

弹幕占用次字幕槽，保留主字幕选择；次字幕已被其他字幕占用时会提示并跳过，不强行抢占。普通字幕按钮和 S 不代替 D 的弹幕开关。

弹幕转换需要 Python 能运行随包转换脚本，并能访问对应弹幕数据；网页调用还需要已有浏览器与外部入口。缺少这些条件不影响基本播放。默认不为低帧率视频自动添加 fps 滤镜。

弹幕字号、不透明度、滚动时长、底部留白和过滤文件可独立配置；修改后重启并重新生成/加载弹幕。入口见[字幕与弹幕参数](configuration.md#4-播放音频字幕与弹幕)、[本机 Python 路径](configuration.md#3-本机路径与外部组件)。

## 5. 播放列表侧窗

P 或底栏 Playlist 按钮显示/隐藏独立侧窗。侧窗通常贴在主窗右侧，与主窗同顶、同高并跟随位置变化，不预留主视频空间；主窗最大化、全屏或右侧空间不足时改为屏幕右侧覆盖显示。

侧窗自身关闭按钮隐藏侧窗，可再次用 P 打开。可拖动侧窗边缘调整宽度，本实例记住宽度；主播放器退出时侧窗关闭。首次显示尽量保留主窗焦点，之后点击侧窗可以操作列表。窗口跟随受桌面、工作区和宿主窗口状态影响，不是新的系统级窗口管理器。

播放列表采用深色底和行首序号。当前播放项使用加粗蓝字、蓝色侧标和低强度底色；选中项使用细蓝轮廓，键盘操作时焦点轮廓加重。搜索后的序号仍对应原队列位置。空队列显示“播放列表为空”，搜索无结果显示“没有匹配的项目”。

默认自动队列只补充同目录、同类别的音视频：视频补视频，音频补音频，不自动混入图片、其他文件或子目录。已有队列不会因这条规则自动清理。

| 在侧窗中操作 | 行为 |
| --- | --- |
| 双击条目 | 跳到该条目 |
| 点击底部计数 | 清除搜索并定位当前播放项，只选中和滚动，不重新播放 |
| 普通 Delete | 仅从队列移除，不删除磁盘文件 |
| 拖动条目 | 重排真实队列，保持当前媒体身份 |
| 从 Explorer 拖入文件、文件夹或列表 | 追加音视频；文件夹只读一层，M3U／M3U8按列表顺序展开 |
| Ctrl+F | 在底部打开搜索并选中文本 |
| 底栏右侧搜索按钮 | 打开／收起左侧的搜索框；收起时清除筛选 |
| 搜索中的普通 Escape | 关闭搜索 |

Ctrl+F、Delete、Escape 是侧窗局部操作，不是全局播放器快捷键；额外修饰键不应假定触发相同动作。搜索文本框编辑期间不把文字输入转发为播放器动作。

在条目上右键会先选中该项，再打开播放列表菜单，不会仅因右键而切换播放。“播放此项”和“从队列移除”作用于右键点中的条目，沿用双击和Delete的行为；移除不删除磁盘文件。右键空白区只显示通用操作。

菜单中的“打开”“追加”提供文件、文件夹和剪贴板入口；还可保存播放列表、搜索、定位当前播放项，以及执行已有的上一项／下一项、首项／末项和打乱顺序。保存针对完整队列，搜索仍只过滤显示。空队列时保存和播放顺序不可用，没有当前项时不能定位。

列表获得焦点后，可用菜单键或Shift+F10打开菜单，方向键选择、Enter执行、Esc关闭；菜单中的Delete移除目标条目，Ctrl+F进入搜索。菜单打开时不会把导航键发给播放器，关闭后的按键重复也不会立刻触发全屏或快进。搜索输入框保留原有文本编辑右键菜单，快捷键提示随已应用的用户键位更新。

在“常用设置 > 窗口”开启“启动时打开播放列表”并保存，下次启动播放器时会自动显示侧窗，空队列也适用。默认关闭；本次启动后仍可用P或关闭按钮隐藏侧窗，换文件不会再次打开。此设置不恢复上次队列或改变播放进度。

搜索框显示时，点击侧窗内输入框以外的区域，首次点击只收起搜索并清除筛选，不执行条目或菜单操作；下一次点击恢复正常操作。点击输入框本身仍可编辑，侧窗失去焦点时也会收起搜索。Ctrl+F打开、Esc关闭的方式保持。

搜索只过滤视图，不修改真实队列。过滤后的跳转、移除与排序仍按原条目身份处理，不会把显示行号当真实队列索引。普通底部显示当前项/总数，搜索时显示匹配数量。

“文件 > 打开文件…”会替换当前队列并播放。只选择一个音视频时，仍按现有设置自动加入同目录的同类文件；选择多个文件时，按选择结果的顺序加入，允许音视频混排，不再补入其他同目录文件。

“文件 > 打开文件夹…”将所选文件夹的音视频组成队列并播放。“追加文件夹到播放列表…”将它们加到队尾。选择器中的“包含子文件夹”默认不勾选，仅处理当前层；勾选后，先加入本层文件，再按子文件夹名自然排序逐个深入。每层的文件也按自然顺序排列，例如第2集在第10集前，同一个子文件夹中的内容保持连续。图片、字幕和播放列表文件不会自动加入。

“包含子文件夹”只作用于这次文件夹选择，不自动沿用到下次操作。把文件夹拖入侧窗或从剪贴板追加时，仍只处理该文件夹当前层；多个输入保持原顺序，文件夹在自己的位置展开。导入后是普通平铺队列，不显示目录树，也不自动同步磁盘变化。

扫描完成前保留当前队列和播放；较慢的扫描会显示可取消的进度窗口，取消时不提交已收集的部分内容。空文件夹或没有可用音视频时，当前队列保持不变。无法读取的子文件夹会跳过并提示数量；所选文件夹本身无法读取时不替换队列。目录链接和junction不会展开，跳过时会提示。数量或路径内容超过处理上限时会整次停止，不把截断的列表当作完整结果。

“文件 > 追加文件到播放列表…”、“文件 > 从剪贴板追加文件或网址”和侧窗拖入文件都将内容加到队尾，不打断当前播放或改变暂停状态。空队列中追加后也不会自动播放，双击队列中的条目即可开始。追加本地文件会跳过队列中已有及本批重复的完整路径，不按同名文件合并。剪贴板只在点击对应菜单时读取。

取消选择或没有有效文件时保留原队列。处理期间队列已变化时，会提示重新选择；没有可加入的文件、文件已在队列中或部分输入被跳过，也会分别提示。侧窗启动失败时仍提示“无法打开播放列表”。

通过“打开文件…”打开本地 M3U 或 M3U8，会按列表中的顺序替换队列并播放首个有效条目，保留重复项和标题，不补入同目录文件。使用追加菜单或把列表文件拖入侧窗，则把整份列表加到队尾，不打断播放；列表中已有的重复项不会去重，和手动追加普通文件的规则不同。

列表直接引用的本地文件缺失时，会跳过并提示数量；全部缺失、内容无法读取或列表为空时，原队列保持不变。相对路径从列表所在文件夹开始寻找；旧编码列表若出现乱码或找不到文件，可先用原软件另存为UTF-8。网址和嵌套列表继续由播放器加载，不提前联网检查或逐层展开；HLS仍作为一段流媒体播放，不把分片列成观看队列。

“文件 > 保存播放列表…”每次都显示保存对话框，输出UTF-8的`.m3u8`。确认位置后保存完整队列及顺序、重复项和可用标题，不受侧窗搜索过滤影响，也不保存观看进度或临时播放设置。媒体在列表同目录或子目录时使用相对路径，方便整组移动；其它位置使用绝对路径，网址保持原文。队列的重排、移除和追加不会自动改写原列表文件。

覆盖已有文件前会确认；取消不会写文件。目标在确认后又被修改时会停止并提示重新保存。保存不会先清空原文件，失败时会提示检查目标；正在保存时不再开启第二次保存。保存完成后再次打开该菜单，可在对话框中选择覆盖或另存。

以上规则适用于套件文件菜单、对应快捷键动作和侧窗拖入；主窗口拖入、资源管理器调起及原生“近期文件”仍按 mpv.net 原有方式处理。ISO、AviSynth 脚本和 Windows 快捷方式需要宿主处理，请拖入播放器主窗口打开；文件菜单直接选择这些类型时会提示并保留当前队列。原有光盘和字幕专用菜单仍可使用。其它列表格式沿用播放器现有支持，不提供相应格式的导出。

鼠标在条目上停留片刻后显示完整路径；网络条目显示标题与 URL，长文本换行。提示会自动隐藏，移动、滚动或点击会取消旧提示。底部计数的“定位当前播放项”提示出现在鼠标附近，仅在计数按钮范围内触发。这些内容仅用于当前列表查看。

Home/End 或 Previous/Next 左键切换上一/下一媒体。手动操作到边界时重播当前项，这不是 Ctrl+R 的保留标记重载入口；自然播放结束则进入下一项，最后一项停留。Previous/Next 其他鼠标键默认解绑，不含隐藏随机或菜单动作。

侧窗会转发一组现有播放器键，但搜索、选择器、控制台和字幕调整有各自焦点边界。修改 input.conf 不保证侧窗任意键位都同步改变；具体配置边界见[快捷键说明](configuration.md#6-快捷键与鼠标动作)及[队列配置边界](configuration.md#7-截图片段与播放列表)。

## 6. 截图与动态片段

Screenshot 按钮集中了源截图、片段标记、输出目录和默认导出格式。默认根目录为 Windows 当前用户的 Pictures 下 `Capture`，可用本机 `capture_root` 指定其他目录。

| 操作 | 行为 |
| --- | --- |
| 左键 | 保存源 PNG，并把图像复制到剪贴板 |
| 右键第一次 | 记录导出起点 A |
| 右键第二次 | 记录晚于 A 的 B，仅导出并复制所选格式 |
| 悬停后选择 WebP/GIF/MP4 | 指定下一次唯一的导出格式 |
| 中键 | 打开 Capture 根目录；必要时创建该根目录 |

PNG 使用源视频帧，排除软字幕、OSD、控制栏和窗口；源内已经烧录的文字仍在。它不是播放器窗口截图。具体截图处理仍受输出驱动影响，不把 PNG 解释为所有渲染和色彩链路的无损复刻；播放器截图语义可参看[mpv 官方说明](https://mpv.io/manual/stable/#screenshot-commands)。

### A/B 导出与格式选择

设置A后，Seekbar下侧出现琥珀色方形端点；选定有效B后显示导出区间，成功或失败即清除。切换媒体后不显示上一媒体的导出范围；无效B保留A。标记仅用于确认范围，不支持拖拽修改。

先在起点右键，再播放或 seek 到终点右键。B 必须大于 A，错误终点会保留 A 并提示；切换媒体清除待导出的 A。忙时拒绝新截图与片段导出，中键打开目录仍是独立操作。确认有效音视频源并开始导出后会清除 A；异步导出失败也不会把 A 自动恢复。

每次有效导出只保存并复制当前所选格式，不同时生成三种最终文件。WebP/GIF仍使用内部临时MP4转换，任务结束会清理它。

右键菜单“截图与片段 > 导出格式”与Screenshot悬停选项一致；“复制最近导出片段”复制最近一次成功结果，不受后来选择的格式影响。导出失败保留上一份成功结果，已有文件不删除；换格式需重新选择A/B导出。

新实例默认导出 WebP。选择在当前实例跨媒体保留，重新打开恢复 WebP；B 点冻结当前任务的导出格式。导出期间改变选项只影响以后任务，不改变已开始的任务。

| 输出 | 当前默认处理 |
| --- | --- |
| PNG | 源图像，实际保存为 PNG |
| MP4 | 源分辨率/帧率，H.264 CRF18、fast、8-bit yuv420p；奇数尺寸补齐偶数 |
| MP4 音频 | 已选内置/外部音轨，AAC192k，并考虑 audio-delay；未选择音轨时无音频 |
| WebP | 从内部临时 MP4 派生，最大边界框960×960、最高20fps、quality75，循环 |
| GIF | 从内部临时 MP4 派生，最大边界框640×640、最高12fps、128色 Bayer 抖动，循环 |

选中的音视频轨若缺少导出所需的源文件或流索引信息，会提示失败；不会猜测另一个音轨替代。

WebP/GIF 保持比例，不放大源图像、不抬高低帧率素材的帧率。GIF 的时间量化可能使实际帧间隔与标称帧率有差异。

导出按源时间线处理，不应用播放倍速，也不烧入软字幕、弹幕或控制栏。MP4 的8-bit编码是兼容取舍；不能据此认为 HDR 或原色彩链路被无损保留。在线源的读取权限、可定位性和请求条件也会影响导出。

### 输出组织与依赖

输出按媒体标题创建安全子目录：去掉一个已识别媒体后缀，例如 `Show.mkv` → `Show`；`Episode.01` 这样的普通标题不去掉 `.01`。非法字符和保留设备名会安全化。

文件名包含安全标题、保存日期时间和实际扩展名。已有文件不覆盖，旧目录不迁移；打开目录使用根目录，而不是推断上一份媒体的输出位置。

源 PNG 与目录入口不依赖 FFmpeg，片段导出需要可用 FFmpeg。缺少依赖或处理失败时会提示，失败只清理本任务产生的文件，不清空剪贴板；播放器正常关闭会取消自己的导出任务。

失败提示可区分FFmpeg缺失、MP4/WebP/GIF编码阶段、保存失败、权限不足、剪贴板失败或临时目录不可用；只显示固定原因，不附媒体URL和私人路径。未能分类时仍使用原通用失败提示，不猜测具体原因。

路径和功能边界见[本机路径配置](configuration.md#3-本机路径与外部组件)、[截图与片段配置](configuration.md#7-截图片段与播放列表)。当前没有可通过新增 conf 字段改 CRF、尺寸、帧率或默认持久格式的接口。

## 7. 增强与显示

增强按钮是空心四角星；悬停或点击可打开五档选择。新实例默认 Original，所选档位在当前实例切换媒体后继续保留。每次加载媒体时会记录其原始渲染设置，选择 Original 可恢复该媒体的这组设置。

| 档位 | 主要效果 | 条件与边界 |
| --- | --- | --- |
| Original | 保留/恢复当前媒体基础渲染设置 | 初始默认；不等于清空用户所有播放器配置 |
| Scaling | 使用预设缩放器和抗振铃设置 | 需要 gpu/gpu-next 渲染输出 |
| Deband | Scaling 基础上启用预设去色带 | 具体画质取决于素材，可能影响细节 |
| Anime4K-L | 固定较轻 CNN shader 链 | 可识别 SDR、允许开关和 shader 文件齐备 |
| Anime4K-S | 固定较强 CNN shader 链 | 相同 SDR 门槛，资源需求取决于 GPU/素材 |

增强浮层正常只显示五个档位，当前档位以蓝色标识；悬停不可用档位或应用失败时，在同一浮层底部显示居中原因，与选项之间用细线分隔，不再出现独立说明气泡。当前素材不支持所选档位时，提示会说明初始化、无视频、渲染器、HDR、元数据未知、缺少shader等具体原因；灰色禁用行也能查看原因。提示随控制栏隐藏，不增加常驻面板。

PQ、HLG、未知传递曲线或不满足 SDR 峰值条件的素材不启用 Anime4K。配置中的允许开关只是放行条件之一，不是确认用户 GPU 已完成验证。

档位控制缩放、去色带和 shader 组，不改变色彩目标、主输出驱动、硬解或播放帧率。默认自动显示目标不是 ICC 校准，也没有把所有显示器强制当作 sRGB。

选择失败时实现尝试回滚受控组并取消成功高亮；可用性和报错应按当前素材/渲染器观察。档名不承诺所有画面都更好或所有 GPU 都实时播放。

没有补帧、RIFE 或自定义组合档。本包也不持久保存上次档位。参数与覆盖关系见[增强与显示配置](configuration.md#8-增强与显示目标)。

## 8. 窗口、信息与快捷操作

打开“工具与设置 > 常用设置…”，选择“快捷键”修改按键。该页提供分类、绑定状态筛选、搜索、行内键帽录入、冲突检查和恢复默认。保存后当前实例立即应用，同一配置目录下的其他实例通常约 1 秒内同步；重新启动、更新和还原时保留个人设置，旧版是否应用这些设置取决于其功能支持。下表列出项目默认键位，个人修改以窗口为准。配置与兼容说明见[用户快捷键](configuration.md#用户快捷键)。

Enter 或视频空白区左键双击切换全屏。Ctrl+T 或 Pin 切换置顶，并显示置顶状态反馈。顶部最小化、最大化、关闭继续使用宿主窗口操作。

Ctrl+0 先离开全屏/最大化，再请求100%窗口比例；窗口仍可能按工作区大小约束，因此不是保证超大视频在屏幕上实现完整像素1:1显示。

Info 按钮、Ctrl+I 或 Ctrl+M 打开媒体信息窗口。概览显示常用信息，详情保留本地文件的完整 MediaInfo 报告；网络媒体显示当前可取得的信息，无法取得完整报告时明确提示。详情支持查找，文字可选择复制；“复制信息”在概览复制概览，在详情复制完整原始报告，查找不会缩减复制内容。窗口显示打开时的媒体信息；切换媒体后再次打开可查看新媒体，重复打开同一媒体会唤回已有窗口。Esc、顶部关闭或右下“确认”均可关闭。

Tab 开关播放器统计，显示时可用数字键切换原有页面，支持滚动的页面可用上下键浏览。统计统一了字体、描边和图表配色，原有字段、页面与采样方式保持。反引号打开控制台。Alt+O 切换 ModernZ 的显示状态；这不重读配置文件，也不切换回原生 OSC。

时间显示右键或 Ctrl+Shift+C 复制当前 `HH:mm:ss.SSS` 时间。没有可读时间时不进行复制。

Ctrl+Shift+V 仅在明确操作时读取剪贴板，加载一条 HTTP(S) URL 并替换当前输入。先去掉首尾空白，余下的内容若仍包含空白、多条地址或本地路径，则不作为此入口接受的 URL；没有浏览器 Cookie 同步或网页嗅探功能。

剪贴板没有内容时提示“剪贴板中没有网址”，内容不符合上述条件时提示“剪贴板网址无效”。这两种情况下，当前媒体和剪贴板内容保持原样。
